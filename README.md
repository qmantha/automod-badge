### AutoMod Badge

### Requirements
- Your bot needs to be in at least 12 guilds.
- All guilds must be dummy/testing servers, because the script will delete ANY existing AutoMod rules before creating new ones.
- Once 100+ rules have been created, you'll need to wait for 24h for the badge to appear on your bot's profile.
- Run `node index.js` to start the script.

### Note
- The script runs sequentially and may take some time.
- This is necessary to avoid hitting Discord's rate limits.
